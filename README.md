# quiblo-iptv.github.io

The landing page for [Quiblo](https://github.com/quiblo-iptv/quiblo-app), served at the root of
`quiblo-iptv.github.io`.

Static HTML, CSS and JavaScript with no build step. That is deliberate: a landing page is one
page, and a toolchain here would be a thing to maintain rather than a thing that helps. Open
`index.html` in a browser, or `python3 -m http.server` in this folder.

## What is where

| | |
| :---- | :---- |
| `index.html` | The whole page |
| `assets/styles.css` | All of it. The two ideas behind the design are written at the top |
| `assets/main.js` | Two behaviours: the hero's channel grid, and the scroll reveal. Both optional — the page works with JavaScript off |
| `assets/` | The icon and the social card, generated by `tools/brand.mjs` in the wiki repository |

## The wiki is a different site

This is the front door. The documentation lives at
[`quiblo-wiki`](https://github.com/quiblo-iptv/quiblo-wiki) and is served from
`/quiblo-wiki/`. **Nothing here changes that URL** — the two sites sit side by side on the same
host and link to each other.

## The brand assets are copies

`assets/quiblo-icon-512.png`, `favicon.ico` and `assets/og-image.png` are generated in the wiki
repository by `tools/brand.mjs`. They are copied here rather than linked so this page renders
even if the other site is down. **Regenerate them there and copy them across** — editing them
here means the two drift.
